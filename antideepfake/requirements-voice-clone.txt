# Packages for voice cloning (scripts/voice_clone/: download_models.py, generate.py, record_reference.py) with
# CosyVoice2-0.5B, Fun-CosyVoice3-0.5B-2512 (official code in third_party/CosyVoice) and Chatterbox (chatterbox-tts).
# Its own conda environment `voice_clone`, Python 3.11 (conda's Python includes tkinter for the recorder).
# Tested on an M4 Max MacBook (macOS, MPS + CPU).
#
# One environment for both model families. Their pins clash only on transformers: CosyVoice pins 4.51.3,
# chatterbox-tts 0.1.7 pins 5.2.0 but its English model runs unchanged on 4.51.3 (5.2.0 was only needed for its
# multilingual model and Gradio app), while CosyVoice's Qwen2 decoding loop (past_key_values) is written for 4.x.
# So chatterbox-tts is installed with --no-deps, and its other dependencies are listed here. Also left out on purpose:
# gradio, spacy-pkuseg, pykakasi, pyloudnorm (chatterbox's web demo, multilingual and Turbo models), and
# CosyVoice's training, serving and TensorRT packages (deepspeed, tensorrt, fastapi, grpcio, tensorboard).
#
# Install (from the antideepfake/ folder):
#   Mac (Apple Silicon):
#     conda create -n voice_clone python=3.11 -y
#     conda activate voice_clone
#     pip install "setuptools<81" wheel
#     pip install --no-build-isolation openai-whisper==20231117   # its old setup.py needs pkg_resources
#     pip install -r requirements-voice-clone.txt
#     pip install --no-deps chatterbox-tts==0.1.7
#   NVIDIA server (Linux): the same, but first install the CUDA build of PyTorch from the PyTorch index (its wheels
#   bundle the CUDA runtime and cuDNN; the driver must support CUDA 12.4, see `nvidia-smi`):
#     pip install torch==2.6.0 torchaudio==2.6.0 --index-url https://download.pytorch.org/whl/cu124
#   onnxruntime below is the CPU build: on CUDA, CosyVoice asks it for the GPU, gets a warning and runs its two small
#   ONNX models (speech tokenizer, speaker encoder) on the CPU, once per clip. For the GPU there, replace it with
#   onnxruntime-gpu (a CUDA 12 build).
# Then get the models: python scripts/voice_clone/download_models.py
