# Bootstrap：得分与模型差距的 95% 置信区间

直接使用现有预测，未重新运行模型。当前纳入模型数：CREMA-D 9; RAVDESS 9; MELD 10。
按组有放回抽样 10,000 次，随机种子 `20261111`；使用 percentile 方法，取两端各 2.5% 分位点。

全体保存样本的分数仍是点估计。Bootstrap 反复改变说话人／对话的构成，观察分数和模型差距如何波动。区间较窄表示在这种组构成变化下较稳定。95% 是区间构造方法的名义覆盖率：若重复取得类似数据并构造区间，目标是约 95% 的区间覆盖总体分数；它不是这一条区间内真实分数的概率。

## 如何解读及限制

- 配对比较只使用双方相同 audio_path 的交集，核对金标／类别规则一致，并对双方使用同一次抽样。差值区间直接来自每次抽样的 A−B，不是两个单模型区间相减；两个单模型区间重叠也不决定差值是否可靠。
- 类别集合固定。invalid 作为错误保留，计入样本数及漏判，不增加一个宏平均类别。某次抽样缺少一类时，该类 recall/F1 按 0 处理；weighted-F1 使用当次抽样的真实类别占比。本次有缺类的重采样数为 0（按不同样本交集计数）。
- 这些是固定模型在当前数据集组构成变化下的近似区间，不包含训练／API 重跑波动。模型可能见过相关训练数据，因此不能据此证明未见说话人的泛化。RAVDESS 仅有 24 位说话人，区间仍需谨慎解读。
- MELD 按对话分组；不同对话可能共享演员或 episode，所以不等于新演员／新 episode 泛化。未做 episode 层级敏感性分析，也未校正多重比较。不能将这些区间直接外推到公司电话。

## 复现与更新

在 `research_paper/` 下运行：

```bash
python scripts/bootstrap.py --resamples 10000 --seed 20261111
```

默认自动发现当前协议下的全部可用模型，并选每个模型／数据集最大的已完成保存结果。新增模型结果后重跑即可更新。相同输入、参数及 NumPy 版本可复现；抽样流由种子和样本交集确定，加入其他模型不改变既有比较。所有结果集中在 [bootstrap.csv](../output/bootstrap.csv)，参数、源文件 SHA256、分组来源与诊断在 [manifest](../output/bootstrap_manifest.json)。CSV 的 estimate／ci_lower／ci_upper 用原始分数尺度保存；本报告乘 100 后显示为百分数或百分点。

方法参考：[SciPy bootstrap 文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.bootstrap.html)（percentile 与 paired 定义）；[Cameron & Miller, 2015](https://cameron.econ.ucdavis.edu/research/Cameron_Miller_JHR_2015.pdf)（整组抽样及少组数的限制；该文讨论回归，本项目仅采用其整组重采样原则）。
