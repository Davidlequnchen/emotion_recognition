-------------------------Code and files illustration----------------------

There are two Python code files: "data collation.py" and "acoustic analysis.py".

"data collation.py" was used to process raw data and generate final corpus data.

Raw data include: "raw_data_actor1.csv" ~ "raw_data_actor6.csv" and "group information.xlsx", a total of 7 files.

Raw data columns illustration:
"raw_data_actor1.csv" ~ "raw_data_actor6.csv":
They will be used in the "data collation.py" 
username: Participants' code, range 20230001 ~ 20230720;
filename: "filename" + ".wav" are audio file names;
emotionresult: participant's emotion type selection result for each audio
intensity: participant's intensity rating result of each audio, range 1~9

"group information.xlsx":
It will be used in the "data collation.py" 
Sheet1: 18 groups of audio file names written in 18 columns
Sheet2: Two columns: filename and group number, respectively
The data content of Sheet1 and Sheet2 are same

The "audio information.xlsx" was generated by running the "data collation.py"
It will be used in the "acoustic analysis.py".
"filename" + ".wav" are audio file names, filename coding rule see "Audio files coding rule".
"actress" is the speaker code, 1~3 are males, 4~6 are females.
"emotioncode" is the emotion type of each audio after validation.
"intensity" is the mean value of 40 participants' emotional intensity assessment (range 1~9),1 means the selected emotion is very slight, 9 means the selected emotion is very strong.
"correct_1" is the mean accuracy assessed by 40 participants, including 0 and 1.
"group number" is the group information, range 1~18.
"neutral" ~"happiness" are the number of participants' responses to the target emotion type ("Emotion code"). The sum of the "Neutral" ~"Happiness" is 40.


"acoustic analysis.py" was used to analyze acoustic information, which could generate data results of Table 6 ~ Table 7.
Please download the audio files from the Folder "audio zips by different emotion", add the appropriate file address to run the "acoustic analysis.py"
